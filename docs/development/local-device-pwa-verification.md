# 実端末・PWAの確認

この手順は、[開発テスト用ローカル環境の構築](local-development-environment.md)を完了した環境を、同じLAN内のスマートフォン、タブレット、別のPCから確認するために使う。YAMORUのPWAはオンライン利用専用であり、オフライン編集・同期、Push通知、家庭データの永続的なオフラインキャッシュには対応しない。

## LAN内の別端末から接続する

開発マシンのIPv4アドレスを`.env.local`の`YAMORU_ALLOWED_DEV_ORIGINS`へ設定する。例えば`192.168.1.10`の場合は次のようにする。

```dotenv
YAMORU_ALLOWED_DEV_ORIGINS=192.168.1.10
```

複数のホストを許可する場合はカンマで区切る。この値はNext.jsの開発サーバーと開発用HTTPS証明書だけに使い、preview / productionには設定しない。

設定後に`npm run dev`を起動または再起動する。ホストが証明書の対象に加わると証明書は自動で再生成される。DHCPによって開発マシンのIPアドレスが変わった場合も、値を更新して再起動する。

別端末を開発マシンと同じLANへ接続し、`https://192.168.1.10:3000`のように設定したホストを開く。

## 別端末でローカルCAを信頼する

LAN内の別端末では、mkcertが発行したローカルCAを信頼するまで証明書の警告が出る。端末間で安全にファイルを転送できる方法を使い、開発マシンの`rootCA.pem`を確認端末へ渡す。認証情報や秘密鍵は転送しない。

iPhoneでは次の手順で設定する。

1. 開発マシンで`npm run dev:cert`を実行し、出力される「ローカルCAの場所」から`rootCA.pem`を確認する。
2. メール添付、iCloud Drive、OneDriveなど、利用者が管理できる方法で`rootCA.pem`をiPhoneへ転送する。
3. iPhoneで`rootCA.pem`を開き、設定 > 一般 > VPNとデバイス管理から構成プロファイルをインストールする。
4. 設定 > 一般 > 情報 > 証明書信頼設定を開き、インストールしたmkcertのルート証明書を「完全に信頼」に切り替える。

この設定は端末ごとに一度だけ必要である。ローカルCAはGit管理対象外であり、開発マシンのmkcert管理領域に置かれる。

## 認証と家庭作成を確認する

1. 別端末から設定したHTTPS URLを開き、未認証時にログイン画面へ移動することを確認する。
2. ローカル環境でbootstrapした認証情報でログインする。
3. ホーム画面が表示され、再読み込み後もログイン状態が維持されることを確認する。
4. アカウント画面で、未登録ならニックネームと最初の家庭を作成する。
5. 再読み込み後も同じ家庭名が表示されることを確認する。
6. ログアウトするとログイン画面へ移動することを確認する。
7. 同じ認証情報で再ログインし、同じ家庭を表示できることを確認する。

## PWAとしてホーム画面へ追加する

### iOS Safari

1. Safariの共有ボタンから「ホーム画面に追加」を選ぶ。
2. 「Webアプリとして開く」をオンにし、名前が「YAMORU」、画像がヤモリアイコンであることを確認する。
3. 追加後にSafariを閉じ、ホーム画面のYAMORUアイコンから起動する。

アイコンを更新した場合は開発サーバーを再起動し、既存のホーム画面アイコンを削除してから追加し直す。ローカルCAを完全に信頼しても追加画面だけが「Y」のモノグラムになる場合は、公開CAの証明書を使うHTTPS環境で最終確認する。

### Android Chrome

1. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ。
2. 表示される案内で「インストール」を選ぶ。
3. Chromeを閉じ、ホーム画面またはアプリ一覧のYAMORUアイコンから起動する。

## 主要導線を確認する

1. ホームの「アカウント」から家族招待画面を開けることを確認する。
2. ホームの「家の台帳」で、名前、種類、任意の外部リンクを持つ管理対象を登録する。
3. 登録した管理対象を開き、完了日基準のメンテナンスTodoを登録する。
4. 「やったよ」から完了し、直近の完了と次回の目安が表示されることを確認する。
5. 再読み込みまたは再ログイン後も、管理対象、Todo、完了記録が失われないことを確認する。
6. 直近の完了を取り消し、未完了のTodoへ戻ることを確認する。
7. 「詳しく記録する」から過去の実施日を指定して完了し、指定した日付で履歴へ記録されることを確認する。

## OK条件

- ホーム画面にYAMORUの名前とヤモリアイコンが表示される。
- アイコンから起動するとブラウザのアドレスバーや操作バーがない独立表示になる。
- 未ログイン時はログイン画面、ログイン済みならホームが表示される。
- ログアウト後は、同じホストのログイン画面へ移動する。
- 家族招待、家の台帳、Todo完了・取消・バックデート完了の主要導線を利用できる。
- 開発サーバーを停止するか機内モードにすると接続できず、以前表示した家庭データをオフライン画面として利用できない。オンラインへ戻して再読み込みすると通常表示へ戻る。

iOSまたはAndroidでメニューが表示されない、独立表示にならない、主要導線を利用できない場合は、端末名、OSとブラウザのバージョン、開いたURL、発生した画面を記録してfollow-up Issueを起票する。
