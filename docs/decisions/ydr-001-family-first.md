# YDR-001: まず家族専用として作る

- 状態: Accepted
- 決定日: 2026-08-12

## 背景

一般公開を前提にすると、課金、規約、サポート、障害対応、商標、移行責任などが初期段階から必要になり、家庭内で本当に役立つかを確認する前に計画が膨らむ。

## 決定

最初は自分の家庭で使う専用アプリとして開発する。一般公開の判断は、数か月以上の家庭内利用実績ができるまで行わない。

## 結果

- 初期の成功指標は利用者数ではなく、家族の継続利用と問題解決になる。
- 一般公開向けの課金、規約、サポート、ストア対応を初期スコープから外す。
- セキュリティと家庭間のデータ分離は、家族専用でも省略しない。

## 見直す条件

- 家族が開発者の補助なしに数か月以上継続利用している。
- 家庭外にも同じ課題がある証拠が得られた。
- 公開後の保守責任を引き受ける意思がある。
