# YDR-009: 初期版から通知機能を外し、ホーム画面へ集約する

- 状態: Accepted
- 決定日: 2026-08-12
- 置き換える決定: [YDR-007](ydr-007-notification-field-trial.md)

## 背景

最初の利用者は自分と家族であり、一般公開向けの通知到達性や複数チャネルを初期から解決する必要はない。Push、メール、カレンダー連携には、端末登録、配信処理、失敗処理、設定UI、外部サービスなどの追加作業が発生する。

YAMORUの初期価値は、アプリを開いたときに家の状態、期限、履歴を正しく確認できることで検証できる。

## 決定

- 初期版にPush通知、メール通知、カレンダー通知を含めない。
- ホーム画面に、期限切れ、今日、近日、最近の実施を常時表示する。
- 要対応件数と期限を、ホーム画面を開いた直後に把握できるようにする。
- 通知設定、NotificationEndpoint、Pushの長期実機検証を初期計画から削除する。
- 通知なしで家庭内運用を行い、実害を観測する。

## 結果

- 通知配信基盤、メールサービス、通知設定UIが不要になる。
- PWAの通知到達性を理由にネイティブ化する必要がなくなる。
- ホーム画面の情報設計と、家族が自発的に確認する頻度が重要な検証対象になる。

## 見直す条件

- アプリを開かないために、期限切れや交換忘れが実際に繰り返し発生する。
- ホーム画面を改善しても問題が解消しない。
- 通知によって防げる具体的な失敗事例が確認できる。

見直す場合も、最初から複数チャネルを実装せず、家庭で最も利用される一つの手段から検証する。
