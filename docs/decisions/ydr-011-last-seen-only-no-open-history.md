# YDR-011: 開封履歴を蓄積せず、最終利用日時だけを任意で保持する

- 状態: Accepted
- 決定日: 2026-08-12

## 背景

通知なし運用の検証目的で、家族ごとの全開封履歴を保存する案が提案された。しかし1家庭だけのMVPでは数値基準の意味が弱く、家族の利用監視に見える可能性もある。

## 決定

- `app_opens`のような開封イベント履歴は作らない。
- 必要であれば`last_seen_at`を1件だけ上書き保持する。
- 最終利用日時は、未使用アカウントや招待の確認など運用目的に限定する。
- ランキング、家族評価、通知要否の自動判定には使用しない。
- ホーム画面の有効性は、期限超過、実施と記録の遅れ、具体的な交換忘れ、家族のフィードバックで判断する。

## 結果

検証のためだけの行動分析基盤をMVPへ追加せずに済む。家庭内ドッグフーディングでは月1回5分程度、期限超過、予定との差、記録の遅れ、具体的な困りごとを確認する。

## 見直す条件

- 一般公開後、利用者の明示的な同意を得た分析が必要になった。
