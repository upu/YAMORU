# YDR-016: 「回ごとに残す」方式の導入時に過去分を自動生成しない

- 状態: Accepted
- 決定日: 2026-08-12

## 背景

月謝や税金向けに「回ごとに残す」方式を後から有効にした際、過去の予定回を自動生成すると、すでに家庭外で処理済みの支払いが大量の未完了Todoとして現れる可能性がある。

## 決定

- 「回ごとに残す」方式はPhase 6で追加する。
- 方式を新規作成または切り替えた時点より前の予定回は自動生成しない。
- 過去の支払いを残したい場合は、利用者が必要な分だけ手動で登録する。

## 結果

将来機能の導入によって、家庭のホーム画面が架空の期限切れTodoで埋まることを防ぐ。

## 見直す条件

明示的な開始日指定や、確認画面付きの限定的な過去分生成が必要になった場合。
