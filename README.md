# YAMORU

暮らしの「いつだっけ？」をなくす。

YAMORUは、家族のTodo、家電や契約などの管理対象、定期メンテナンス、実施履歴を一か所で扱う家庭運営アプリです。

## ドキュメント

- [プロダクト計画](docs/product/yamoru-project-plan.md) - ビジョン、対象利用者、MVP、ロードマップ
- [開発資料](docs/development/index.md) - ローカル開発環境、テスト、実端末・PWA確認
- [意思決定](docs/decisions/index.md) - 現在有効な判断と、その背景・見直し条件
- [運用・参照資料](docs/references/index.md) - データベース変更、認証管理、Cloudflare運用などの手順
- [プロジェクトガイド](AGENTS.md) - このリポジトリで作業するときの約束
